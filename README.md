# 数字原子数列字典 · Digital Atomic Number Dictionary

**爱与灵科技 · 开源字典体系**
**AGPL-3.0**

---

## 这是什么

一套完整的汉字→编码→频谱坐标→英文单词的映射体系。

## 数据流

```
50位01序列（频谱坐标）
      ↕
5位编码（00001-6758）
      ↕
中文单字
      ↕
英文单词（30001-41184）
```

两个中文组合 → 频谱交叉 → 产生语义 → 翻译为英文单词

## 核心概念

- **不动点** — 6758个核心汉字，每个有唯一5位编码（00001-6758）
- **相位数列** — 每个汉字对应50维二进制频谱坐标
- **十维认知** — 我/在/想/生/活/不/能/停/下/道，十个认知维度
- **英文映射** — 英文单词编码从30001开始，与汉字编码空间隔离
